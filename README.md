# 철의 왕관

2~6명이 각자의 PC에서 동시에 접속하는 실시간 중세 영지 전략 게임입니다.

## 게임 시작

1. 방을 열 PC에 Node.js 20 이상을 설치합니다. 다른 플레이어는 브라우저만 있으면 됩니다.
2. 저장소를 내려받아 압축을 풀고 호스트 PC에서 `start.bat`을 실행합니다. 터미널에서는 `node server.cjs`로 시작할 수 있습니다.
3. 호스트는 브라우저에서 `http://localhost:8080`을 엽니다. 같은 Wi-Fi 또는 유선 네트워크의 다른 플레이어에게는 서버 창에 표시된 **Other PCs** 주소를 보냅니다.
4. 각자 영주 이름과 비어 있는 성을 선택합니다. 접속이 막히면 호스트의 Windows 방화벽에서 개인 네트워크에 대한 Node.js 연결을 허용했는지 확인합니다.

호스트 PC에서 서버 창을 열어 두어야 합니다. GitHub는 소스 저장소입니다. 서로 다른 네트워크에서 플레이하려면 모든 플레이어가 접근할 수 있는 Node.js 호스트에서 서버를 실행해야 합니다.

## 게임 규칙

- 20초마다 금화와 식량을 얻습니다. 농지는 수입을 늘리고, 성벽은 성의 방어력을 높입니다.
- 이웃 성에 식량과 금화 교역을 제안하거나 2분 휴전을 협상할 수 있습니다. 상대 영주가 수락하면 적용됩니다.
- 출정한 군대는 12초 뒤 도착합니다. 공격 병력이 도착 시점의 주둔 병력과 성벽 방어력의 합계를 넘으면 승리합니다. 공격에서 3번 이긴 영주가 왕관을 차지합니다.
- 게임은 호스트의 `realm-save.json`에 자동 저장됩니다. 재접속할 때 처음 로그인한 브라우저와 같은 서버 주소를 사용하세요. 새 게임을 시작하려면 서버를 끈 뒤 이 저장 파일을 다른 곳으로 옮기고 서버를 다시 실행하세요.
