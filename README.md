# 철의 왕관

최대 4명이 각자의 왕을 조종하는 브라우저용 실시간 3D 중세 왕국 게임입니다. 플레이어가 맡지 않은 왕국은 AI가 운영합니다.

## GitHub Pages 배포

1. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch → main → / (root)**를 선택하고 저장합니다. 이미 설정되어 있으면 다음 단계로 넘어갑니다.
2. Firebase 프로젝트 `test-649b1`의 **Authentication → Sign-in method**에서 **Anonymous**, **Google**, **Email/Password**를 활성화합니다. Google 로그인에 필요한 프로젝트 지원 이메일도 선택합니다.
3. **Authentication → Settings → Authorized domains**에 `mingeon101.github.io`를 추가합니다.
4. **Realtime Database → Rules**에서 `database.rules.json`의 `ironCrownV1` 부분을 기존 `rules` 안에 추가하고 게시합니다. 기존의 다른 프로젝트 경로 규칙은 보존합니다. 새 데이터베이스에서는 파일 전체를 사용할 수 있습니다. 상위 경로에 공개 읽기·쓰기 허용 규칙이 있으면 하위 규칙만으로 해당 권한을 제한할 수 없습니다.
5. GitHub Pages 빌드가 완료되면 [게임 주소](https://mingeon101.github.io/middle_age_game/)를 엽니다. 한 명이 방을 만들고, 나머지는 초대 링크나 12자리 코드로 같은 방에 접속합니다.

[GitHub Pages 게시 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Firebase Authentication](https://firebase.google.com/docs/auth/web/start) · [Realtime Database 규칙](https://firebase.google.com/docs/database/security)

## 조작

- **WASD** 또는 방향키로 이동합니다. 왕은 열린 들판에서 달리고 성내 도로와 건물 안에서는 속도를 줄입니다. **Shift**를 누르고 있으면 웅크리고, **Space**로 점프합니다.
- 3D 월드는 브라우저 창을 채웁니다. **F** 또는 **전체화면** 버튼으로 브라우저 전체화면으로 전환합니다. **왕국 관리** 버튼으로 명령 패널을 열거나 접습니다.
- 마우스를 움직이면 왕과 카메라가 같은 방향을 향합니다. **마우스 시점** 버튼이나 게임 화면을 한 번 클릭하면 커서를 고정해 계속 둘러볼 수 있습니다. **Esc**로 고정을 해제합니다. **V**는 1인칭과 3인칭을 전환하고, 마우스 휠은 3인칭 카메라를 확대하거나 축소합니다.
- 성문을 지나 주택, 상점, 왕궁에 들어갈 수 있습니다. 내 왕궁 안쪽 책상 앞에서 **E**를 누르면 집무실이 열립니다. 집무실에서 왕국 현황, 수교국·교전국, 세수와 국민소득을 확인하고 수교를 제안하거나 무기를 강화합니다.
- **M** 또는 **지도** 버튼으로 네 성, 길, 강과 내 위치를 봅니다. 성문에는 경비병이 서고 성벽에는 보초가 순찰합니다.
- 내 성 근처에서 **군사 훈련**을 명령합니다. 백성 3명과 금화 15, 식량 12가 소모되고 60초 후 병력 3명이 충원됩니다.
- **P** 또는 **왕국 통계** 버튼으로 인구, 국민소득, 상품 매출, 세금소득, 병력 및 훈련 진행을 확인합니다.

## 왕국 운영

- 각 왕국은 30초마다 백성이 1명 늘어납니다. 수교국이 있을 때만 백성이 상품을 만들어 판매합니다. 30초마다 수교국당 상품 8개까지 판매할 수 있으며, 백성 한 명이 상품 한 개를 만듭니다.
- 상품 한 개의 판매가는 10금화입니다. 1금화가 세금으로 국고에 들어가고, 나머지 9금화는 국민소득에 쌓입니다.
- AI는 농지를 확장하고 군사를 훈련하며, 조건에 따라 제안에 응답하거나 출정합니다. 사람이 AI 왕국에 입장하면 그 왕국의 현재 상태를 인수합니다.
- 출정하려면 집무실에서 대상 왕국에 선전포고해야 합니다. 수교 중이거나 휴전 중일 때는 선전포고할 수 없습니다. 무기 강화는 단계마다 공격과 주둔 병력의 전투력을 15%포인트 높입니다.
- 공격에서 세 번 승리하면 왕관을 차지합니다. 로그인한 계정으로 같은 방에 다시 접속하면 맡았던 왕국으로 돌아갑니다.

방 시계를 기준으로 낮과 밤, 맑음·흐림·안개·비가 바뀝니다. 밤에는 성문과 성내 가로의 횃불이 켜집니다. 건물 안에서는 비가 보이지 않습니다.

GitHub Pages 버전은 추가 게임 서버 없이 동작하며, 적어도 한 명의 플레이어가 접속 중일 때 경기 진행을 계산합니다. 방 상태는 Realtime Database 트랜잭션으로 동기화됩니다. 참가자의 브라우저에서 경기 규칙을 계산하므로 신뢰하는 사람끼리 하는 게임용이며, 경쟁전용 서버 검증은 포함되어 있지 않습니다.

기존 LAN 버전은 `start.bat`으로 시작할 수 있습니다. GitHub Pages는 루트 `index.html`의 3D 버전을 실행합니다.
